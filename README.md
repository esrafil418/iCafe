# ☕ Cafe Menu

An interactive and dynamic restaurant/cafe menu application built with **React** and **Bootstrap 5**.  
Click on any category to filter and display only the menu items from that category.

![Cafe Menu Preview](public/1.png)

---

## ✨ Features

- 🔘 **Dynamic category filtering** (All, Breakfast, Lunch & Shakes.)
- 🎨 **Beautiful responsive design** with Bootstrap 5
- ⚡ **Instant UI updates** without page refresh
- 📱 **Fully responsive** (Mobile, Tablet, Desktop)
- 🎯 **Active button highlighting** for current category
- 🖼️ **Image display** for each menu item
